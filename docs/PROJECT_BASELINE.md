# Website 2.0 工程基线

建立日期：2026-07-22

## 来源边界

- 旧网站继续在线运行，作为视觉、内容与交互验收基线。
- 新工程不复制旧仓库的 `.git` 历史。
- 新工程不复制旧站 2.1 MB 的单文件 `index.html`，避免陈旧代码进入 2.0。
- 旧任务汇报、失败代码、参考录屏和废弃工作流不纳入新仓库。

## 已导入资料

- `docs/handoff/`：8 份交接文档。
- `src/data/`：7 份结构化数据与素材清单。
- `public/assets/original-rendered-scenes/`：31 张原始 3D 渲染素材。
- `public/assets/deployed-extracted/`：24 张线上实际使用素材。

原始交接包保持在独立归档位置，不在本仓库重复保存 ZIP 文件。

## 基线验收

- `npm run lint` 必须通过。
- `npm run build` 必须通过。
- GitHub Pages 构建产物固定为 `dist/`。
- Vite部署路径固定为 `/website/`。
- 仓库转为 Public 并启用 Pages 前，不执行正式上线切换。
