# 技术与部署说明

## 当前线上技术

当前成品是无构建步骤的静态网站：

- 原生 HTML、CSS、JavaScript
- Hash 路由
- JSON 以内嵌 `application/json` 脚本保存
- 图片以内嵌 base64 保存
- GitHub Actions + GitHub Pages 部署

推送 `main` 后，`.github/workflows/deploy-pages.yml` 将整个仓库作为静态站发布。

## 本地预览

当前成品可以直接打开 `source/bjgm-media-lab/index.html`。为避免浏览器对本地文件的限制，也可以在仓库目录运行：

`npx serve .`

## 新项目推荐基线

建议重新建立：

- Vite + TypeScript
- React 或保持原生组件化方案，二选一后固定
- GSAP + ScrollTrigger 处理滚动时间线
- Three.js 仅承担确有价值的镜头、透视和图片贴片，不用粗糙几何体冒充最终视觉
- Canvas 处理蒸汽、火光、液面等自然动态
- HTML Overlay 处理导航、时间轴和无障碍信息
- 独立 JSON/TypeScript 数据文件和独立图片资源

## 部署注意

- GitHub Pages 项目路径为 `/bjgm-media-lab/`，Vite 重构时需设置正确 `base`。
- 保留现有 Pages workflow，或改为先构建再上传 `dist/`。
- 正式上线前补充 favicon、分享图、SEO 描述和正式邮箱。
- 图片不要继续全部 base64 内嵌；使用 WebP/AVIF、明确尺寸和懒加载。
- 新项目应增加桌面与移动端截图回归测试。
