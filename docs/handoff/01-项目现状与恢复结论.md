## 线上成品实际结构

当前仓库不是 Vite/TypeScript/Three.js 源工程，而是一个可以直接部署的静态单文件网站：

- `index.html`：约 2.1MB，包含 HTML、CSS、JavaScript、JSON 数据和 36 处内嵌图片。
- `.github/workflows/deploy-pages.yml`：推送 `main` 后自动发布 GitHub Pages。
- `.nojekyll`：禁止 Jekyll 处理静态文件。
- `README.md`：旧版简要部署说明，文本编码显示异常。

线上页面包含 7 个路由：

1. 主页 `#home`
2. 账号历程 `#history`
3. 作品库 `#works`
4. 创作方法论 `#method`
5. 资产库 `#assets`
6. 账号详情 `#detail`
7. 关于实验室 `#about`

## 重要判断

当前线上站适合作为“可运行成品与视觉验收基线”，不适合继续长期扩写。下一阶段应新建模块化工程，并逐页迁移数据、样式和交互。

原本讨论过的 Vite + TypeScript + Three.js + GSAP 方案没有保存在云端仓库中，因此不能声称已恢复该源工程。新项目若继续采用这套技术，需要重新搭建，但本交接包已经保留了需求、素材、线上结果和部署逻辑。
