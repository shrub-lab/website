# 重启开发路线图

## 阶段 0：冻结基线

- 保留本交接包，不直接覆盖 `source/bjgm-media-lab/`。
- 用线上地址和本地 `index.html` 建立桌面、移动端基准截图。
- 确认 4 个账号、20 条作品及资产库哪些是真实内容，哪些是演示内容。

验收：线上结果、代码提交、素材和内容数据均可追溯。

## 阶段 1：新建模块化工程

- 建立 Vite + TypeScript 工程。
- 配置 GitHub Pages 的项目路径与构建部署。
- 建立路由、全局字体、颜色、间距和响应式基础。
- 迁移 `data/`，补充稳定 ID 和类型定义。

验收：空壳页面可构建、可部署，数据可读取。

## 阶段 2：迁移主站静态页面

按主页、作品库、资产库、方法论、关于实验室的顺序迁移。每迁移一页，都与线上基线比较，避免一次性重写导致内容丢失。

验收：信息架构、内容和核心交互达到当前线上水平。

## 阶段 3：重做团队历程空间

- 先实现名做茶友会 2023 年 8 节点。
- 使用 31 张原始渲染素材建立分层场景。
- 再接入滚动镜头、文字切换、视差和局部动态。
- 先保证首帧构图和逐节点聚焦，再增加蒸汽、火光与液面细节。

验收：满足 `04-名做茶友会团队历程规格.md` 的所有要求。

## 阶段 4：内容校准与发布

- 替换占位邮箱和占位数据。
- 校验账号外链、作品日期、标题和数据。
- 优化图片格式、首屏加载与低性能设备降级。
- 验证桌面、平板、手机和减少动态模式。

验收：构建通过、线上可访问、核心路径无控制台错误、视觉无重叠。

## 不应带入新项目的内容

- 未上线的旧版失败代码。
- 用简陋程序几何体替代渲染素材的方案。
- 与最终页面无关的临时录屏、尝试脚本和一次性工作流。
- base64 单文件继续扩写的结构。
- 无法确认来源或真实性的占位运营数据。
