## 四个场景

### 场景 1：茶台总览

首帧核心画面。纯白空间中的长条茶台采用轻俯拍视角，五个物体依时间由近到远排列：

`三色茶叶 → 紫砂壶 → 功夫茶杯 → 竹制工具 → 透明煮茶壶`

每件物品保留独立空间、焦点和 hover 区域。茶台本身承担时间轴透视。

### 场景 2：双皮奶

石锅灶台、蒸笼、双皮奶碗、火光、蒸汽与扇子组成独立空间。鼠标靠近时火光变暖、蒸汽变浓、扇子轻摆。

### 场景 3：摩卡咖啡

大理石桌、咖啡研磨器、手冲滤杯、摩卡杯与咖啡豆组成独立空间。鼠标靠近时研磨器手柄微转、滤杯高光移动、咖啡液面轻晃。

### 场景 4：双皮奶替代构图

允许复用场景 2 素材，但镜头角度、物体缩放和信息区域必须不同，使其成为独立作品节点。
