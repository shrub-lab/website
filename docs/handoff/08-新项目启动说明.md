1. `README.md`
2. `docs/01-项目现状与恢复结论.md`
3. `docs/02-设计理念与视觉原则.md`
4. `docs/03-信息架构与内容模型.md`

## 可直接用于新任务的开场说明

> 重启“灌木新媒体实验室 website”项目。请先完整阅读本交接包 README 与 docs，不要立即改代码。线上站和 GitHub 仓库是现状基线，原始 31 张渲染素材是团队历程页的最终视觉来源。新项目需要保留现有主站的信息架构，同时用模块化 Vite + TypeScript 工程逐步迁移。第一阶段先完成代码基线、数据模型和部署，不做视觉重写；第二阶段再按《名做茶友会团队历程规格》重做滚动空间。禁止使用低质量程序几何体替代渲染素材。

## 第一轮应确认的四个问题

1. 新项目是否继续使用 `macabyavaha7-sys/bjgm-media-lab` 仓库。
2. 团队历程采用最初 8 条作品，还是线上详情中的 10 条展示内容。
3. 现有 7 个页面哪些必须保留，哪些可延期。
4. 资产库是公开下载功能，还是只展示团队能力。

在四项口径明确前，可以搭建工程与迁移数据，但不应批量重写页面内容。
