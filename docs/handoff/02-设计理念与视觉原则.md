# 设计理念与视觉原则

## 核心定位

灌木新媒体实验室网站不是营销落地页，而是“内容实验室的数字档案空间”。它需要同时表达三件事：

1. 团队做过什么：作品、账号与时间历程。
2. 团队如何工作：方法论、素材与生产流程。
3. 团队是什么：以中国文化、新媒体影像和技术实验为核心的创作组织。

## 视觉关键词

- 高级、极简、克制
- 纯净白色空间
- 黑体系统字体
- 真实渲染素材优先
- 轻量空间层次与镜头叙事
- 信息清晰，不用装饰压过内容

统一字体：

`"PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", "Helvetica Neue", Arial, sans-serif`

## 团队历程页的叙事逻辑

历程页不是普通纵向列表，而是“镜头沿时间推进”。文字提供时间、作品与数据，画面提供物体、空间和情绪；两者必须同步。

初始画面先建立账号与年份，再逐个聚焦作品。每个作品节点有独立画面主体、独立 hover 区域和独立信息反馈。滚动结束后，场景收束成账号阶段总览，为下一个账号做过渡。

## 画面原则

- 背景保持纯白，不建立房间、窗户、墙面、灯笼或复杂中式布景。
- 中国文化感来自茶具、竹、石、蒸汽、火光、材质和构图，而不是符号堆砌。
- 真实 3D 渲染图片是主视觉，程序绘制的简陋几何体不能替代最终素材。
- 茶台五件物品必须按时间顺序由近到远，保留明确间距。
- 场景 2、3、4 作为独立空间进入，不能与茶台场景堆叠。
- 竹林、石草、地面阴影、淡雾只承担空间深度，透明度和对比度必须低于主体。

## 动效原则

- 动效服务“逐渐打开内容、呈现画面故事”，避免为了炫技而连续旋转或漂浮。
- 滚动改变镜头焦点，文字同步淡入淡出。
- 鼠标视差按远景、中景、前景递增。
- 局部动态必须贴合物理直觉：蒸汽、火焰、液面、高光、扇子和手柄。
- 动效幅度小、速度缓、具备惯性；用户停止操作后画面应稳定。
- 支持 `prefers-reduced-motion`，移动端减少视差和粒子效果。

## 信息设计原则

- 顶部导航保持极简，当前页面以加粗或下划线高亮。
- 账号名、年份、作品名、日期和数据形成固定信息层级。
- 页面不展示与当前阶段无关的年份。
- 紧凑工具界面使用小标题，不在信息面板中使用英雄级字号。
- 卡片只用于重复项目或确有边界的内容，不把所有区块都做成浮动卡片。
